# Prompt — Character Reference Sheet (Image)

Use with an image generator that accepts a reference image. Fill from the [Character Bible](../templates/character-bible.md).

```text
Create an original fictional character reference sheet for [CHARACTER NAME].
Use the supplied approved reference image as the identity reference.
Preserve the same facial structure, age appearance, hairstyle, eye color,
skin tone, body proportions, and distinctive features.
Outfit: [EXACT OUTFIT]. Accessories: [EXACT ACCESSORIES].
Show: front portrait, three-quarter portrait, side profile, and full-body view.
Neutral studio background, realistic cinematic character design,
natural anatomy, consistent identity, no text, no logos, no watermark.

Avoid: changing facial identity, changing hairstyle, changing age,
changing clothing, extra fingers, distorted hands, asymmetrical eyes,
plastic skin, duplicate people, text artifacts.
```

## Expression variant

```text
Using the approved reference image for [CHARACTER NAME], create a close-up
portrait with a [neutral / angry / afraid / sad / suspicious / relieved]
expression. Same face, hair, age, outfit: [EXACT OUTFIT].
Soft cinematic lighting, plain dark background, no text, no watermark.
```
