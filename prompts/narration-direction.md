# Prompt — Narration Delivery Direction

Add delivery tags to the locked script before generating voice. Use whatever tag syntax your voice tool supports.

```text

words. Mark:
- [pause 1s] / [pause 2s] before reveals and after cliffhangers
- [slower] for tense build-ups, [faster] for action
- [whisper] / [low] for secrets
- Emotion tags for dialogue lines: [cold], [afraid], [angry], [calm]
- Phonetic spellings in brackets after hard names, e.g. Marla [MAR-luh]

Pronunciation list:
[PASTE FROM CHARACTER BIBLE]

Script:
[PASTE FINAL SCRIPT]
```
