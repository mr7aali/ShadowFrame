# Prompt — Outline

**Step 2 of the script pipeline.** Input: one chosen premise from step 1.

```text
Build a beat-by-beat outline for a 14-minute narrated YouTube episode of an
original fictional crime thriller.

Premise: [PASTE CHOSEN PREMISE]
Story shape: [e.g., locked-room]

Recurring cast (from the Character Bible — use exactly as written):
[PASTE CHARACTER DESCRIPTIONS]

Use this structure and word budget (150 words per minute):
[0:00-0:30]  Hook — start mid-action with a shocking moment or question (~75 words)
[0:30-3:00]  Setup — protagonist, setting, stakes, the crime (~375 words)
[3:00-7:00]  Investigation — clues, suspects, red herring (~600 words)
[7:00-10:00] Complication — a twist, a death, or a betrayal (~450 words)
[10:00-13:00] Climax and reveal (~450 words)
[13:00-14:00] Ending — consequence plus a chilling last line (~150 words)

Requirements:
- 5–6 named characters, maximum 7. Distinct names with different first letters.
  Extras are called by role, never named.
- No more than one new named character per minute.
- The real culprit appears early so the reveal is fair.
- List every clue and where it is planted; show how the ending pays each off.
- A cliffhanger at roughly every 2–3 minutes.
- U.S. details must be correct (police ranks, sheriff vs. city police, 911,
  dollars, miles, 12-hour clock).
- Output: one bullet per beat, with the timestamp section it belongs to.
```
