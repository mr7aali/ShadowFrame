# Prompt — Title and Description

```text
Write YouTube packaging for this original fictional crime-thriller episode.
Audience: adults in the U.S., UK, Canada, and Australia.

Script summary: [PASTE 3–4 SENTENCE SUMMARY — include the twist so you can avoid it]

Give me:
1. 5 title options, under 60 characters, with a clear hook and no clickbait
   that the video doesn't deliver (style example: "The Detective Who Never
   Closed Case #47").
2. A description whose first two lines hook the viewer without spoiling the
   twist, followed by:
   - Episode number and series/playlist name: [SERIES]
   - "This story is a work of fiction. Any resemblance to real people or
     events is coincidental."
   - Credits line for music/voice if a license requires it: [CREDITS]
3. 3 thumbnail text options of 3–4 words each.
4. A pinned-comment question that invites real discussion (no engagement bait).
```
