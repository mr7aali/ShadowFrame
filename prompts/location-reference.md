# Prompt — Location Reference (Image)

Create one approved reference per recurring location and reuse it for every shot there.

```text
Create a cinematic establishing reference image of [LOCATION NAME], a
fictional location in [TOWN/CITY TYPE, e.g., small Midwest town].
Description: [ARCHITECTURE, KEY OBJECTS, LAYOUT, SIGNAGE STYLE].
Time of day: [TIME]. Weather: [WEATHER]. Era: [DECADE].
Mood: grounded, dark, suspenseful crime thriller.
Lighting: [e.g., sodium streetlights, wet reflections].
Realistic, 16:9, no people, no readable text, no real brand logos,
no watermark.
```
