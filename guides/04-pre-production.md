# 04 — Pre-production and Scene Planning

Template: [scene breakdown](../templates/scene-breakdown.md)

- [ ] Break the approved script into scenes.
- [ ] Scene list: number, location, time of day, characters, action, narration/dialogue, emotional purpose.
- [ ] Shot list per scene (wide, medium, close-up, insert, POV, establishing).
- [ ] Storyboard or keyframe image for important shots.
- [ ] Location/environment reference for each recurring place.
- [ ] Prop list (phone, evidence bag, keys, photographs, documents).
- [ ] Continuity sheet: clothing, injuries, weather, time, props, positions, what each person knows.
- [ ] Aspect ratio: 16:9 for episodes, 9:16 for Shorts.
- [ ] Frame rate and resolution fixed before production.
- [ ] Mark which shots need lip-sync and which can run under narration (prefer narration).
- [ ] Identify difficult action shots early and simplify them if AI can't render them reliably.
