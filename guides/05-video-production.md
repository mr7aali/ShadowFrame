# 05 — AI Image and Video Production

Related prompts: [shot prompt](../prompts/video-shot.md) · [location reference](../prompts/location-reference.md) · [character reference sheet](../prompts/character-reference-sheet.md)

## Reference images
- [ ] Generate and approve character references before any scene generation.
- [ ] Generate location references and reuse them for matching scenes.
- [ ] Generate key prop/evidence references where continuity matters.
- [ ] Use image/reference guidance where the video tool supports it.
- [ ] Keep a prompt log for every approved shot.

## Video clips
- [ ] Generate shot-by-shot — never ask for a whole episode at once.
- [ ] Specify subject, action, location, time, framing, camera movement, lighting, mood, duration.
- [ ] One clear action per shot.
- [ ] Use the approved character reference for every recurring character shot.
- [ ] Match clothing, props, weather, and lighting to the continuity sheet.
- [ ] Generate alternate takes for important shots.
- [ ] Review face, hands, eyes, motion, background, object continuity, artifacts.
- [ ] Reject clips with identity drift, broken anatomy, accidental text/logos, or confusing movement.
- [ ] Avoid excessive camera movement.
- [ ] Use establishing and reaction shots to hide difficult transitions.
- [ ] Keep selected clips in the edit folder; keep rejects separate.

## Visual quality review
- [ ] Does the character match the approved reference?
- [ ] Is the action understandable without explanation?
- [ ] Do hands, face, eyes, and body move naturally?
- [ ] Is the environment consistent across connected shots?
- [ ] Any flicker, morphing, duplicated objects, or glitches?
- [ ] Does the shot match the scene's emotional tone?
- [ ] Is there enough variety to avoid a slideshow feel?
