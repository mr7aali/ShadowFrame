# 07 — Editing and Finishing

- [ ] Create a project at the chosen aspect ratio, resolution, and frame rate.
- [ ] Import only approved video, audio, and graphics.
- [ ] Assemble in narrative order.
- [ ] Remove dead time and repetitive shots.
- [ ] Match narration/dialogue to the correct shot.
- [ ] Add accurate English captions and proofread them (many viewers watch muted).
- [ ] Use transitions sparingly; prefer motivated cuts.
- [ ] Color-correct and apply a consistent grade.
- [ ] Balance narration, dialogue, music, ambience, and effects.
- [ ] No black frames, frozen frames, or gaps.
- [ ] Short branded end screen with a relevant next-video prompt.
- [ ] Watch the entire export start to finish.
- [ ] Review once on headphones and once on a phone speaker.
- [ ] Export a high-quality master and back up the editable project.
