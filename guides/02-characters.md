# 02 — Characters

Create the main character before producing episodes. Keep a **Character Bible** as the source of truth ([template](../templates/character-bible.md)). Use fully fictional characters; never copy a real person, celebrity, or copyrighted character.

Related prompts: [character reference sheet](../prompts/character-reference-sheet.md) · [voice sample](../prompts/voice-sample.md)

## A. Character foundation
- [ ] Full name and nickname (if any).
- [ ] Age range, occupation, and story role.
- [ ] Central goal.
- [ ] Greatest fear.
- [ ] Strongest quality and biggest flaw.
- [ ] Backstory in 3–5 sentences.
- [ ] The secret they are hiding.
- [ ] The moral line they won't cross — and what might make them cross it.
- [ ] How the character changes over the season.

## B. Visual identity
- [ ] Face shape, skin tone, eye shape/color, nose, lips, other distinctive non-sensitive traits.
- [ ] Hairstyle, hair color, facial hair, grooming.
- [ ] Body build and approximate height.
- [ ] Signature outfit and 1–2 alternates.
- [ ] Accessories (watch, ring, glasses, bag).
- [ ] Signature color or visual motif.
- [ ] Posture, gestures, typical expressions.
- [ ] Reference images: front portrait, 3/4 view, side profile, full body.
- [ ] Expression references: neutral, angry, afraid, sad, suspicious, relieved.
- [ ] Wardrobe references for every recurring outfit.
- [ ] Save approved images as locked references; do not casually regenerate the face between scenes.

## C. Voice identity
Full voice workflow: [06-voice-and-audio.md](06-voice-and-audio.md)
- [ ] Voice type, age impression, accent.
- [ ] Speaking speed, pitch, texture, emotional range.
- [ ] Dialogue style (short/direct, sarcastic, formal, hesitant).
- [ ] Pronunciation list for names and places.

## D. Consistency pack
- [ ] Fixed character description (paste unchanged into every prompt).
- [ ] Exact clothing and accessory descriptions per scene.
- [ ] Approved reference image filenames/IDs.
- [ ] Voice model/settings and pronunciation notes.
- [ ] Continuity rules (scar, watch, hairstyle, dominant hand must not change).
- [ ] Avoid list for common visual errors (face drift, extra fingers, changing clothes, inconsistent age, text artifacts).
- [ ] Test the character in at least 5 camera shots and 3 lighting conditions.
- [ ] Reject outputs that change identity; regenerate or use a reference-guided workflow.
- [ ] Keep a versioned backup of the Bible and references.

## E. Cast size for a 14-minute story

Viewers can't scroll back to remember who is who. Aim for **5–6 named characters**, hard maximum 7.

| Role | Count | Purpose |
|---|---|---|
| Protagonist (detective/investigator) | 1 | Carries the story; one flaw, one goal |
| Victim | 1 | Sets the crime in motion |
| Antagonist (real culprit) | 1 | Appears early so the reveal feels fair |
| Suspects (one is the red herring) | 2 | Keep viewers guessing |
| Supporting (partner, witness, informant) | 1 | Someone for the protagonist to talk to |
| Unnamed extras | Any | Called by role, never by name |

- Give characters distinct, easy names (different first letters and lengths): Ray, Marla, Detective Cole.
- Introduce each with one memorable detail; repeat it when they return.
- No more than one new named character per minute.
- For a series, keep the same protagonist and partner; rotate the rest.

## F. Supporting cast
- [ ] A mini-bible for each recurring character.
- [ ] Each visually and vocally distinguishable.
- [ ] Relationship to the protagonist defined.
- [ ] What each knows, wants, and hides.
- [ ] A relationship map.
