# AI Crime Thriller YouTube Channel — Complete Production Checklist

**Project type:** Original English-language fictional crime-thriller videos  
**Format target:** 8–12 minute episodes, plus Shorts  
**Production approach:** AI-assisted / semi-automated; human review before publishing  
**Status key:** `[ ]` Not started · `[x]` Completed · `[!]` Needs attention

> Use this as a master checklist. Complete the channel setup and character bible first. Then use the episode checklist for every video. Tool names are examples, not endorsements; check current pricing, commercial-use terms, and availability before committing.

---

## 1. Channel strategy and identity

### Channel concept
- [ ] Write a one-sentence channel promise: what viewers will consistently get.
- [ ] Choose the main subgenre: detective mystery, psychological thriller, serial-killer investigation, courtroom mystery, heist, or supernatural crime.
- [ ] Decide whether stories are standalone or part of a connected series.
- [ ] Define the target audience and intended language/accent (e.g. international English / US-oriented English).
- [ ] Choose a tone: grounded realistic, dark cinematic, fast-paced, investigative, or psychological.
- [ ] Set a content boundary: fictional stories only; do not present invented events as real news or true crime.
- [ ] Define the channel's unique selling point (e.g. recurring detective, twist endings, detailed clues, moral dilemmas).
- [ ] Choose a realistic publishing schedule (start with one polished long-form video every 1–2 weeks).
- [ ] Decide the target length (recommended starting range: 8–12 minutes).
- [ ] Define how Shorts will support long-form episodes (teasers, clues, character moments—not unrelated filler).

### Brand assets
- [ ] Choose a distinctive channel name and check availability on YouTube and other social platforms.
- [ ] Check that the name/logo does not imitate an existing studio, franchise, or creator.
- [ ] Create a simple logo and profile image.
- [ ] Create a channel banner with readable text on mobile and desktop.
- [ ] Choose 2–3 brand colors and 1–2 readable fonts.
- [ ] Create a thumbnail template, but vary each thumbnail to match its episode.
- [ ] Write the channel description and explain that the stories are fictional if that could otherwise be unclear.
- [ ] Create a short channel intro/outro only if it improves the viewing experience; avoid long intros.
- [ ] Create a consistent end-screen layout.

## 2. Original character creation — A to Z checklist

Create the main character before producing episodes. Keep a **Character Bible** as the source of truth. Use a fully fictional character and avoid copying a real person, celebrity, or copyrighted character.

### A. Character foundation
- [ ] Choose the character's full name and nickname (if any).
- [ ] Choose age range, occupation, and story role.
- [ ] Define the character's central goal.
- [ ] Define what the character fears most.
- [ ] Define their strongest quality and biggest flaw.
- [ ] Write their backstory in 3–5 sentences.
- [ ] Decide what secret they are hiding.
- [ ] Decide what moral line they will not cross—and what might make them cross it.
- [ ] Define how the character changes over the season.

### B. Visual identity
- [ ] Define face shape, skin tone, eye shape/color, nose, lips, and other distinctive non-sensitive visual traits.
- [ ] Define hairstyle, hair color, facial hair (if any), and grooming.
- [ ] Define body build and approximate height consistently.
- [ ] Define signature clothing (main outfit) and 1–2 alternate outfits.
- [ ] Define accessories (watch, ring, glasses, bag, etc.).
- [ ] Choose a signature color or visual motif.
- [ ] Define posture, gestures, and typical facial expressions.
- [ ] Create a front-facing portrait reference.
- [ ] Create a 3/4 view reference.
- [ ] Create a side-profile reference.
- [ ] Create a full-body reference.
- [ ] Create expression references: neutral, angry, afraid, sad, suspicious, relieved.
- [ ] Create wardrobe references for every recurring outfit.
- [ ] Save the approved images as locked references; do not casually regenerate the character's face between scenes.

### C. Voice and performance identity
- [ ] Choose a voice type and age impression.
- [ ] Choose accent and pronunciation style; keep it consistent.
- [ ] Define speaking speed, pitch, texture, and emotional range.
- [ ] Create a pronunciation list for names and locations.
- [ ] Generate and approve a short voice sample.
- [ ] Confirm the voice provider permits the intended commercial use.
- [ ] Do not clone another person's voice without clear permission and appropriate rights.
- [ ] Create a dialogue style guide (short/direct, sarcastic, formal, hesitant, etc.).

### D. Character consistency pack
- [ ] Write a fixed character description (copy/paste unchanged into prompts).
- [ ] Record exact clothing and accessory descriptions per scene.
- [ ] Record approved reference image filenames/IDs.
- [ ] Record voice model/settings and pronunciation notes.
- [ ] Record continuity rules (e.g. a scar, watch, hairstyle, or dominant hand must not change).
- [ ] Create a negative prompt / avoid list for common visual errors (face drift, extra fingers, changing clothes, inconsistent age, text artifacts).
- [ ] Test the character in at least 5 different camera shots and 3 lighting conditions.
- [ ] Reject outputs that visibly change identity; regenerate or use a reference-guided workflow.
- [ ] Keep a versioned backup of the Character Bible and approved references.

### E. Supporting cast
- [ ] Create a separate mini-bible for each recurring character.
- [ ] Make each character visually and vocally distinguishable.
- [ ] Define each character's relationship to the protagonist.
- [ ] Define what each character knows, wants, and hides.
- [ ] Create a relationship map.
- [ ] Limit the number of important characters in the first episode so the audience can follow the story.

## 3. Story development and writing

### Story concept
- [ ] Write a one-line premise (logline).
- [ ] Decide the central mystery/crime and the emotional stakes.
- [ ] Decide who the audience follows and why they care.
- [ ] Create a beginning, escalation, reveal, climax, and resolution.
- [ ] Plant clues before the reveal; make the twist fair in hindsight.
- [ ] Check that the culprit's motive and actions make sense.
- [ ] Avoid plot holes, impossible timelines, and unexplained character knowledge.
- [ ] Make the story original; do not rewrite a film, TV episode, book, game, or another creator's script.
- [ ] Research real-world details only when needed; do not copy protected expression.

### Script structure for an 8–12 minute episode
- [ ] 0:00–0:20 — Cold open / compelling mystery.
- [ ] 0:20–1:00 — Establish protagonist, setting, and stakes.
- [ ] 1:00–3:00 — First discovery and initial suspects.
- [ ] 3:00–6:00 — Investigation, conflict, and new clues.
- [ ] 6:00–8:30 — Reversal / misleading assumption challenged.
- [ ] 8:30–10:30 — Reveal and climax.
- [ ] Final 20–40 seconds — Emotional consequence and a satisfying hook or ending.
- [ ] Adjust timings to the actual story; do not stretch a short story just to hit a duration.

### Script quality control
- [ ] Read the script aloud and fix unnatural dialogue.
- [ ] Remove repetitive exposition and unnecessary narration.
- [ ] Make every scene change the plot, reveal character, or build tension.
- [ ] Give each speaker a distinct voice and vocabulary.
- [ ] Check spelling, grammar, names, dates, and locations.
- [ ] Confirm the ending pays off the clues introduced earlier.
- [ ] Keep a final approved script version; do not generate visuals from a draft that may change.

## 4. Pre-production and scene planning

- [ ] Break the approved script into scenes.
- [ ] Create a scene list with scene number, location, time of day, characters, action, dialogue, and emotional purpose.
- [ ] Create a shot list for each scene (wide, medium, close-up, insert, POV, establishing shot).
- [ ] Create a storyboard or keyframe image for important shots.
- [ ] Create a location/environment reference for each recurring place.
- [ ] Create a prop list (phone, evidence bag, keys, photographs, documents, etc.).
- [ ] Create a continuity sheet: clothing, injuries, weather, time, props, character positions, and what each person knows.
- [ ] Decide aspect ratio (16:9 for standard YouTube; 9:16 for Shorts).
- [ ] Decide frame rate and output resolution before production; use a consistent project setting.
- [ ] Mark which shots require dialogue/lip-sync and which can use voice-over.
- [ ] Identify difficult action shots early and simplify them if AI cannot render them reliably.

### Scene breakdown template

|---|---:|---|---|---|---|---|---|

## 5. AI image and video production

### Reference images
- [ ] Generate and approve character references before scene generation.
- [ ] Generate location references and reuse them for matching scenes.
- [ ] Generate key props/evidence references where continuity matters.
- [ ] Use image/reference guidance where the chosen video tool supports it.
- [ ] Keep a prompt log for every approved shot.

### Video clips
- [ ] Generate clips shot-by-shot rather than asking for an entire 10-minute film at once.
- [ ] Specify subject, action, location, time, camera framing, camera movement, lighting, mood, and duration.
- [ ] Keep each shot focused on one clear action.
- [ ] Use the approved character reference for every recurring character shot.
- [ ] Match clothing, props, weather, and lighting to the continuity sheet.
- [ ] Generate alternate takes for important shots.
- [ ] Review face, hands, eyes, motion, background, object continuity, and unwanted artifacts.
- [ ] Reject clips with identity drift, broken anatomy, accidental text/logos, or confusing movement.
- [ ] Avoid excessive camera movement if it makes the action unclear.
- [ ] Use establishing shots and reaction shots to hide difficult transitions naturally.
- [ ] Save only selected clips in the final edit folder; keep rejected generations separate.

### Reusable shot prompt template

```text
Use the approved reference image for [CHARACTER NAME].
Scene: [WHAT IS HAPPENING].
Location: [PLACE AND DETAILS]. Time/weather: [DETAILS].
Character action: [ONE CLEAR ACTION]. Emotion: [EMOTION].
Framing: [WIDE / MEDIUM / CLOSE-UP / POV].
Camera: [STATIC / SLOW DOLLY / PAN / TRACKING].
Lighting: [LIGHTING]. Mood: [MOOD].
Visual style: grounded cinematic crime thriller, realistic lighting,
natural movement, coherent anatomy, consistent character identity.
Continuity: [CLOTHING, PROPS, INJURIES, POSITION].
No subtitles, no captions, no logos, no watermark, no random text.
```

### Visual quality review
- [ ] Does the character look like the approved reference?
- [ ] Is the action understandable without explanation?
- [ ] Do the hands, face, eyes, and body move naturally?
- [ ] Does the environment remain consistent across connected shots?
- [ ] Are there any flicker, morphing, duplicated objects, or visual glitches?
- [ ] Does the shot match the scene's emotional tone?
- [ ] Is there enough visual variety to avoid a slideshow-like result?

## 6. Voice, dialogue, music, and sound design

### Voice
- [ ] Generate narration only after the script is approved.
- [ ] Assign a consistent voice to each character.
- [ ] Use emotion and delivery direction where supported.
- [ ] Keep pronunciation consistent for names and locations.
- [ ] Check dialogue timing against the visuals.
- [ ] Re-record/regenerate lines that sound robotic, rushed, or emotionally wrong.
- [ ] Check commercial-use rights and voice-cloning permissions.

### Music and sound effects
- [ ] Choose music that supports tension without overpowering dialogue.
- [ ] Add location ambience (rain, traffic, room tone, wind, footsteps, etc.).
- [ ] Add sound effects only when they match visible action.
- [ ] Use silence intentionally before important reveals.
- [ ] Duck music under dialogue.
- [ ] Check loudness consistency and remove clipping, hiss, and harsh peaks.
- [ ] Keep proof of licenses/permissions for music and sound effects.
- [ ] Do not use popular commercial songs unless you have the required rights.

## 7. Editing and finishing

- [ ] Create a project at the selected aspect ratio, resolution, and frame rate.
- [ ] Import only approved video, audio, and graphic assets.
- [ ] Assemble the story in narrative order.
- [ ] Remove dead time and repetitive shots.
- [ ] Match dialogue to the correct character and shot.
- [ ] Add subtitles/captions and proofread them.
- [ ] Use transitions sparingly; prefer motivated cuts.
- [ ] Add color correction and a consistent grade across scenes.
- [ ] Balance dialogue, narration, music, ambience, and effects.
- [ ] Check that no clip has black frames, frozen frames, or accidental gaps.
- [ ] Add a short branded end screen and a relevant next-video prompt.
- [ ] Watch the entire export from beginning to end before upload.
- [ ] Review once on headphones and once on a phone speaker.
- [ ] Export a high-quality master and keep an editable project backup.

## 8. Thumbnail, title, metadata, and publishing

### Packaging
- [ ] Choose one clear visual idea for the thumbnail.
- [ ] Make the main subject readable at small mobile size.
- [ ] Use short text only if it adds useful context.
- [ ] Do not use misleading imagery or promise a scene that is not in the video.
- [ ] Write 3–5 title options and choose the clearest compelling title.
- [ ] Make the first two lines of the description explain the story without spoiling the twist.
- [ ] Add relevant playlist, episode number, and fictional-story notice where appropriate.
- [ ] Add accurate captions/subtitles.
- [ ] Add end screens and cards where useful.
- [ ] Check spelling of title, description, and thumbnail text.

### Upload checklist
- [ ] Confirm the video is original and all assets have appropriate rights.
- [ ] Select the correct audience setting; do not mark content as made for kids unless it is actually intended for children.
- [ ] Complete any required altered/synthetic-content disclosure honestly, following YouTube's current rules.
- [ ] Check copyright checks and restrictions in YouTube Studio.
- [ ] Confirm visibility, schedule, playlist, language, and subtitles.
- [ ] Preview the watch page after processing.
- [ ] Pin a relevant comment if useful; do not use misleading engagement bait.
- [ ] Save the final title, description, thumbnail, upload date, and asset/license records.

## 9. YouTube policy, copyright, and monetization safety

- [ ] Make the story, script, characters, dialogue, and editing meaningfully original.
- [ ] Do not mass-produce near-identical videos with only names or images changed.
- [ ] Do not reuse other creators' footage, movie scenes, music, or artwork without permission or a valid legal basis.
- [ ] Do not assume that AI-generated means copyright-free or automatically safe for commercial use.
- [ ] Check the terms of every AI image, video, voice, music, and editing service.
- [ ] Keep invoices, plan details, license terms, and permission records.
- [ ] Avoid impersonating real people or making synthetic media that could mislead viewers about real events.
- [ ] Label fictional stories clearly where viewers could mistake them for real cases.
- [ ] Follow YouTube's current altered/synthetic content disclosure requirements when applicable.
- [ ] Follow YouTube's current advertiser-friendly guidelines; graphic violence, shocking imagery, and sensationalized crime can limit ads.
- [ ] Never promise monetization. Eligibility and approval depend on current YouTube Partner Program requirements and channel review.
- [ ] Recheck YouTube policies before launch and whenever policies change.

## 10. Analytics and improvement

Review each video after publishing:
- [ ] Check impressions and click-through rate (CTR).
- [ ] Check the first 30-second audience retention.
- [ ] Find the exact timestamps where viewers leave.
- [ ] Check average view duration and percentage viewed.
- [ ] Review traffic sources and geography without assuming every viewer is in the target country.
- [ ] Read comments for confusion, story requests, and character feedback.
- [ ] Compare thumbnail/title performance over time; change only when there is a reason.
- [ ] Identify the strongest scene and the weakest scene.
- [ ] Record one improvement for the next episode.
- [ ] Do not judge the channel from one upload; look for patterns across several videos.

## 12. First episode: practical launch checklist

### Before production
- [ ] Finalize channel concept and name.
- [ ] Complete protagonist Character Bible.
- [ ] Create and approve the protagonist's visual reference pack.
- [ ] Approve the protagonist's voice sample.
- [ ] Create at least two supporting characters if the story needs them.
- [ ] Write and approve the first original story.
- [ ] Complete the scene breakdown and shot list.

### During production
- [ ] Generate location and prop references.
- [ ] Generate all required shots using approved character references.
- [ ] Review and select the best takes.
- [ ] Generate narration and character dialogue.
- [ ] Add licensed music, ambience, and sound effects.
- [ ] Edit the complete episode.

### Before publishing
- [ ] Complete the visual, audio, story, and continuity review.
- [ ] Create thumbnail and title.
- [ ] Add description, captions, playlist, and end screen.
- [ ] Check rights, licenses, and YouTube disclosure settings.
- [ ] Upload privately/unlisted first and inspect the processed video.
- [ ] Schedule or publish when everything passes review.
- [ ] Record analytics and lessons after release.

## 13. Recommended production principles

1. **Lock the character before making episodes.** A strong reference pack saves time and reduces face drift.
2. **Write first, generate second.** Do not spend credits generating shots for a script that is still changing.
3. **Create shots, not entire films, with video AI.** Build the episode from short controlled clips.
4. **Use human quality control.** AI can create visual errors, continuity mistakes, and awkward dialogue.
5. **Prioritize story and sound.** A compelling story and clean sound often matter more than flashy effects.
6. **Keep everything documented.** Save prompts, approved references, source files, project files, and licenses.
7. **Start small.** Produce one polished pilot before trying to automate a high-volume schedule.
8. **Verify current tool terms and platform policies.** Features, pricing, and commercial-use rules can change.

## 14. Definition of done — an episode is ready only when

- [ ] The story is original, coherent, and entertaining.
- [ ] The characters remain recognizable and consistent.
- [ ] The visuals are clean and understandable.
- [ ] Dialogue is clear, natural, and correctly assigned.
- [ ] Music and effects are balanced and properly licensed.
- [ ] The edit has no obvious glitches or continuity errors.
- [ ] Thumbnail/title accurately represent the episode.
- [ ] YouTube metadata and required disclosures are complete.
- [ ] The full exported video has been watched and approved by a human.
- [ ] Project files and rights records are safely backed up.
